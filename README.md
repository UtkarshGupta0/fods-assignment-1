# CS F320 Assignment 1: Multi-modal Feature Extraction

Feature extraction and comparison across images (RGB, multispectral, hyperspectral, thermal),
video (RGB, thermal), speech audio and text, plus notes on tensors, TensorFlow and TPUs.
Python only, developed on Google Colab.

Work in progress. Modalities are added one at a time.

## Layout
- `src/` feature-extraction scripts, one per modality
- `data/` datasets and feature cache (git-ignored)
- `results/` benchmark table and figures
- `notebooks/` Colab notebooks
- `report/` final report
